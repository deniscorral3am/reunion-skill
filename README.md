# Claude Meetings en tus llamadas de venta

El documento y la skill de Claude para activar Claude Meetings (Claude dentro de tu Google Meet) y usarlo en tus
llamadas de venta para cerrar más clientes.

| Parte | Qué tienes |
|---|---|
| Qué es | Qué hace Claude Meetings, qué guarda, planes, límites y precio (beta, Team y Enterprise, solo Google Meet) |
| Activarlo | Paso a paso: plan, admin, invitados externos (imprescindible para clientes), Google Meet, herramientas conectadas y prueba sin cliente |
| La llamada de venta | Qué pedirle antes, durante y después, el aviso de consentimiento de la transcripción y la propuesta al colgar con las palabras del cliente |
| El prompt | Para pegarlo en Claude y que te prepare tu próxima llamada |

Hecho por Denís Corral · [@deniscorralvillarraso](https://instagram.com/deniscorralvillarraso) · [Sell Your AI](https://sellyourai.io)

## Cómo usarlo

- **Solo leer:** abre [`DOCUMENTO.md`](DOCUMENTO.md). Al final está el prompt para pegar en Claude.
- **Como skill de Claude Code:**

  ```bash
  git clone https://github.com/deniscorral3am/reunion-skill ~/.claude/skills/reunion
  ```

  Abre Claude Code y escribe `/reunion`.

Fuente: artículo oficial de Anthropic sobre Claude Meetings y su [centro de ayuda](https://support.claude.com/en/articles/18325154) (12/11/2026). Es una beta: puede cambiar.
